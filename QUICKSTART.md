# 🚀 Quick Start Guide - HyperWeather

## Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Train the Model (if not already trained)
```bash
python train_model.py
```

### Step 3: Run the Application
```bash
python app.py
```

🌐 **Open**: http://127.0.0.1:5000

## Troubleshooting

**Q: Location not found?**
- A: Check spelling of city/state names. Use standard Indian city names.

**Q: No data for selected date?**
- A: Try selecting a date within the next 5 days for best accuracy.

**Q: Charts not showing?**
- A: Make sure JavaScript is enabled. Check browser console for errors.

**Q: Geolocation not working?**
- A: Allow location access when browser asks, or use manual entry.
